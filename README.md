# NYC Citi Bike Ridership and Weather Analysis

## Project Overview

This project builds an analysis-ready dataset combining daily NYC Citi Bike ridership with daily weather observations from LaGuardia Airport.

The data was prepared using Google BigQuery and SQL.

## Data Sources

- NYC Citi Bike Trips
- NOAA Global Surface Summary of the Day (GSOD)

## Repository Structure

- `code/` - Python notebooks for Part 2
- `data/` - Final exported CSV dataset
- `queries/` - SQL used to build the dataset
- `docs/` - Supporting documentation

## Final Dataset

The final dataset will be stored as:

`data/citibike_weather_daily.csv`
